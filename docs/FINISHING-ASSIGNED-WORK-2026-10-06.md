## Configuration and schema safety

Migrations `015`–`017` are additive; old migration files/checksums are untouched. Upgrade testing preserves legacy certification fields, existing content and explicit permission denies. A deployment's read-only `verify-migrations` gate refuses missing or changed migrations. An operator must separately review and apply the additive migrations to a recovered, backed-up environment.

Device access remains disabled until `ACCESS_CARD_HASH_KEY` and `ACCESS_READERS_JSON` are configured. Use independently generated keys of at least 32 characters; never use examples or commit actual keys. Changing the card-hash key requires an explicitly planned card re-enrollment/rotation, not silently losing existing assignments. `ACCESS_READERS_JSON` is an array of objects: `id`, `secret`, `kind` (`building`, `room`, `equipment`) and `resourceId` for room/equipment. Provision secrets only to their designated Pi/readers.

Deployment requires separate GitHub staging/production environments, required production reviewers, required main CI branch protection, GHCR pull permission on RLES, pre-created release roots, a readable protected application env file, an existing Docker network, and loopback reverse-proxy ports. Set environment secrets `RLES_HOST`, `RLES_PORT`, `RLES_USER`, `RLES_SSH_KEY`, `RLES_KNOWN_HOSTS`; variables `RLES_RELEASE_ROOT`, `RLES_ENV_FILE`, `RLES_DOCKER_NETWORK`, `RLES_HTTP_PORT`. ## Reporting definitions

Receipt revenue uses original purchase/recording date and **current confirmed refund state**, not reconstructed historical cash movements. Pending payments and unconfirmed refunds are not receipts/refunds. Studio receipts are included separately; current original-card payment records retain their existing audit trails. CSV preserves structured column values; spreadsheet-leading formulas are neutralized.

Booking utilization's denominator is the full selected calendar window, not unconfigured business opening hours. Reader-authorized intervals are unioned to avoid counting repeated renewal leases twice. Neither is proof a machine physically operated. Room check-ins are visits, not current headcount; current reader leases and verified class attendance are explicitly separate. Active users means distinct users with an approved check-in in the selected period.
